# MLB Strikeout MVP Implementation Plan

> **For agentic workers:** Three cooperating agents implement in parallel against `docs/mlb/CONTRACT.md`. The lead agent owns shared schemas and integrates. Do not invent alternate column names.

**Goal:** Reproducible hobby MLB starter strikeout PMFs with a fixture backtest and daily CLI.

**Architecture:** Immutable snapshots → cutoff-strict pitcher-game features → OOF workload NB → penalized strikeout NB PMF → chronological evaluation and market comparison.

**Tech Stack:** Python 3.12, pandas, pyarrow, duckdb, statsmodels, scipy, scikit-learn, pytest, ruff, mypy, YAML config, argparse CLI.

## Global Constraints

- Python 3.12; package `src.mlb`; imports `from src.mlb...`
- pandas DataFrames at every boundary; datetime columns `datetime64[us, UTC]`
- Seed all RNG with `MlbConfig.seed` (42)
- Network tests must use saved fixtures; production ingest may call Baseball Savant CSV and MLB Stats API with rate limits
- Do not modify NBA modules except adding MLB-only dependencies
- Do not implement advanced models listed as out of MVP scope
- Feature set version: `k_mvp_v1`; model version: `nb_k_v1`; parser version: `1.0.0`
- Column names and function signatures in `docs/mlb/CONTRACT.md` are binding
